# Recipe Project
This project is part of The Odin Project curriculum. The goal of this project is to create a basic recipe website using HTML.

In this project, I will build a webpage for a delicious Biryani recipe. The website will include ingredients, preparation steps, and images to make the recipe easy to follow.

By completing this project, I will have demonstrated the following skills:

- Creating and structuring HTML pages
- Using headings, paragraphs, lists, and links
- Adding images to a webpage
- Organizing files and folders properly
- Using Git and GitHub for version control
- Writing clean and readable code
